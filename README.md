<H1>Dotfiles Qtile Arch Linux</H1>

Este repositorio contiene la configuración personalizada del entorno de escritorio Qtile sobre Arch Linux, diseñada para ofrecer una experiencia de usuario eficiente y visualmente atractiva.

Características

    Gestor de ventanas: Qtile, un gestor de ventanas en mosaico altamente configurable escrito en Python.​

    Sistema operativo: Arch Linux, conocido por su simplicidad y personalización.

Requisitos

    Arch Linux instalado.​

    Python 3.​

    Qtile.​

    Dependencias adicionales según las configuraciones y scripts utilizados.​
